## 🔬 TP1 — Introduction to PyTorch

> **Notebook:** `TP_Introduction_to_PyTorch_(2).ipynb`

Covers the fundamentals of PyTorch tensors:

- ✅ Creating tensors (scalars, vectors, matrices)
- ✅ Data types and type casting
- ✅ Element-wise & matrix operations
- ✅ Aggregation (min, max, mean, sum, argmax)
- ✅ Reshaping, stacking, squeezing, permuting
- ✅ Indexing & broadcasting
- ✅ NumPy ↔ PyTorch conversion
- ✅ Reproducibility with random seeds
- ✅ GPU acceleration

## ⚡ Quick Start

1. Open any notebook in **Google Colab**:
   - Click on the `.ipynb` file → `Open in Colab`
2. Set GPU runtime: **Runtime → Change runtime type → T4 GPU**
3. Run all cells: **Runtime → Run all** (`Ctrl+F9`)
