# Artificial Intelligence

Course materials and practical work for the Artificial Intelligence module.

## Contents

- `AI Lecture 2 Neural Network Foundations.pdf` - lecture notes on neural network foundations.
- `Lesson1_Introduction-to-Artificial-Intelligence.pdf` - introductory Artificial Intelligence lesson.
- `TP1.ipynb` - practical work notebook for TP1.

## Requirements

To run the notebook, install:

- Python 3
- Jupyter Notebook or JupyterLab

Start Jupyter with:

```bash
jupyter notebook
```

Then open `TP1.ipynb`.
